# Chiang Mai Trip 2026

Офлайн-первый PWA-справочник поездки в Чиангмай 8–19 августа 2026. Статика без сборщика и без внешних CDN: открывается с домашнего экрана телефона и работает в авиарежиме.

**Живая версия:** https://chefml.github.io/chiang-mai-trip/

## Возможности

- Расписание по дням (8–19 августа), горизонтальные вкладки-чипы
- Заголовок дня: дата, описание, загруженность в виде 5 звёзд
- Карточка активности: время, название, заметка, бейджи категории/приёма пищи/«опционально»
- Кнопка **«Проложить маршрут»** → Google Maps directions, вторичная ссылка **«На карте»**
- **«Маршрут по точкам дня»** — одна ссылка со всеми остановками дня по порядку: старт от текущего местоположения, остальные точки уходят в `waypoints`
- Три языка: English, Русский, 中文 — переключатель в шапке, выбор запоминается
- Тема переключается автоматически по времени суток телефона: светлая 07:00–19:00, тёмная ночью
- Полностью офлайн после первой загрузки (service worker, cache-first)

## Установка на телефон

Открыть ссылку выше в Chrome (Android) или Safari (iOS) → меню → **«Добавить на экран „Домой“»**. Один раз запустить приложение с сетью, чтобы service worker закэшировал файлы; после этого работает офлайн. Переходы в Google Maps требуют сети или офлайн-карт Google.

## Локальная разработка

Service worker требует http(s) — `file://` не подойдёт:

```bash
npx serve
```

## Структура

```
index.html                        разметка и контейнер приложения
styles.css                        весь CSS, mobile-first, светлая и тёмная темы
app.js                            загрузка данных, рендер, i18n, deep links, регистрация SW
chiang-mai-trip-data.i18n.json    данные поездки на трёх языках
manifest.json                     манифест PWA
sw.js                             service worker, cache-first
icons/                            icon.svg — источник, icon-192.png, icon-512.png
chiang-mai-pwa-spec.md            исходное техническое задание
```

Иконки пересобираются из `icons/icon.svg`:

```bash
rsvg-convert -w 192 -h 192 icons/icon.svg -o icons/icon-192.png
rsvg-convert -w 512 -h 512 icons/icon.svg -o icons/icon-512.png
```

## Данные

Всё содержимое — в `chiang-mai-trip-data.i18n.json`. Текстовые поля (`trip.title`, `day.title`, `day.weekday`, `location.name`, `location.note`) — объекты `{en, ru, zh}`. Строки интерфейса — в `ui` по коду языка. Коды `category` и `meal` языконезависимы, подписи берутся из `ui[lang].categories` / `ui[lang].meals`.

Точка без `lat`/`lng` и без `placeId` (например, «заправиться по пути») рендерится как напоминание — без кнопок карты.

### Нормализация при загрузке

Файл данных берётся как есть, а `app.js` приводит его к нужному виду в `normalize()`. Обе правки раньше делались руками в JSON и терялись при каждой перегенерации:

- у `trip.title` остаются первые два сегмента, разделённые тире («Chiang Mai — Mae Rim — City» → «Chiang Mai — Mae Rim»)
- у точки с `id`, оканчивающимся на `-fuel`, и без `placeId` координаты обнуляются — это напоминание дозаправиться, а не место на карте; запись с настоящим `placeId` не трогается

## Обновление данных

1. Отредактировать `chiang-mai-trip-data.i18n.json`
2. Поднять версию кэша в `sw.js` (`cm-trip-v2` → `cm-trip-v3`)
3. `git push` — телефон подтянет новую версию при следующем онлайн-открытии
